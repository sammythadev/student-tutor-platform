Prop Type Default className string - CardTitle # The CardTitle component is used for the card title. Prop Type Default className string - CardDescription # The CardDescription component is used for helper text under the title. Prop Type Default className string - CardAction # The CardAction component places content in the top-right of the header (for example, a button or a badge). Prop Type Default className string - CardContent # The CardContent component is used for the main card body. Prop Type Default className string - CardFooter # The CardFooter component is used for actions and secondary content at the bottom of the card.
